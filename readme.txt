VolksTerm 0.1
=============

300 baud PETSCII terminal for C64 OS
with software pulse dialing, for
"dumb" user-port modems with the
Commodore 1650 pinout (Volks 6420).

Installation
============

- copy VolksTerm.car to the
  Applications directory using File
  Manager
- double-click VolksTerm.car in File
  Manager
- click EXTRACT when the INSTALLER
  utility opens

Usage
=====

Type the number, then RETURN (or
C=+D) to dial. Any key aborts while
dialing. C=+X hangs up. CTRL+C=+H
goes home.

Set the C64 OS network driver to
None, so no driver claims the user
port.
